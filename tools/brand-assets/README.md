# Brand asset generation

The single approved artwork input is `design-system/public/assets/logo.svg`. It is a review sheet, not a directly embeddable product image. The exporter extracts its main, 24px, and 16px circular masks into equivalent closed paths and preserves its colors and application plate. Unexpected mask shapes stop generation so a changed design cannot silently export incorrectly.

## Commands

From the repository root, install this isolated development dependency and generate or verify all copies:

```sh
pnpm --dir tools/brand-assets install --frozen-lockfile
pnpm --dir tools/brand-assets generate
pnpm --dir tools/brand-assets check
```

Node.js 20.9+ and Sharp's supported native runtime are required. `check` compares regenerated bytes without writing files. The manifest records the source SHA-256 and every output SHA-256. The social-card raster uses Arial/sans-serif from the generation host; use the same font environment when verifying that raster across machines. Client runtimes do not depend on this tool, Node, or Sharp.

## Consumers

| Surface           | Generated resources                                                                                                 |
| ----------------- | ------------------------------------------------------------------------------------------------------------------- |
| Design catalog    | Main/24/16 SVG marks, explicit theme variants, plate SVG/PNG, ICNS, browser icons                                   |
| Avalonia          | StreamGeometry resource for themed in-app identity, PNG for About/Dock, ICO for Windows windows/EXE, ICNS for macOS |
| Linux desktop     | `packaging/linux/icons/hicolor/` with PNG sizes 16–512 and scalable SVG                                             |
| Website / Web App | Theme-specific transparent marks, adaptive SVG favicon, multi-resolution ICO, opaque 180px Apple touch icon         |
| Android           | Legacy mipmaps at all five densities, round icons, adaptive foreground/background, API 33 monochrome layer          |
| Shared Compose    | Optical 24px vector drawable, tinted by the current theme                                                           |
| iOS               | Opaque 1024px square for default/dark, grayscale 1024px tinted source, asset-catalog entries                        |
| Website sharing   | 1200×630 SVG and PNG; Open Graph and Twitter use PNG                                                                |

ICO entries: 16, 24, 32, 48, 64, 128, 256px. ICNS includes 16–1024px and Retina entries. PNG-compressed containers are generated directly without an OS conversion utility. Compatibility `suncode-logo-small` names point to the new application icon. The original review sheet remains unchanged.

macOS uses a separate export: the unchanged application artwork is scaled uniformly into an 824×824px area centered on a transparent 1024×1024px canvas (100px inset per side). `suncode-macos-1024.png` drives the live Dock override; all ICNS entries use the same composition. The catalog previews it as `platform/suncode-macos.svg`. Keep this padding in the asset rather than applying a different runtime scale.

For Linux installations, copy published `share/applications/` and `share/icons/` into the corresponding installation prefix (or the user's XDG data directory), preserving the hicolor structure. The desktop entry's `Icon=suncode` resolves that installed theme icon. Refresh the desktop/icon cache as appropriate to the package manager. A copied `.desktop` file by itself cannot resolve an uninstalled theme icon.

## Review

Review `#/core/assets/brand` in both themes, then affected product headers, About, browser tabs, and platform launcher icons. Android masks and iOS corner radii are owned by the OS. Do not add platform masks to the iOS source or a second plate to an adaptive Android foreground. Functional UI icons, file-type glyphs, collaborator initials, and project-directory initials are separate from product branding.
