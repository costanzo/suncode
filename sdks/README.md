# Suncode SDKs

Language SDKs live here. They wrap the native runtime boundary and do not own durable state, credentials, provider calls, SQLite, or project operations.

The Phase 1 product ships the Qt desktop app and the Rust runtime SDK facade. TypeScript and Python SDKs are planned packaging surfaces and are intentionally represented here only by placeholders until implementation starts.

Planned layout:

```text
sdks/
  typescript/
  python/
```
