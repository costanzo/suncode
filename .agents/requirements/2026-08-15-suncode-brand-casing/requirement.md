# Requirement

## Background

The product brand used the legacy mixed-case spelling in application chrome, UI copy, native type names, QML module names, assets, and project documentation. The canonical spelling is `SunCode`.

## Goals

- Use `SunCode` consistently wherever the product name is presented or expressed as a PascalCase identifier.
- Keep the desktop application buildable and its QML resources loadable after the rename.

## Non-goals

- Rename stable lowercase technical identifiers such as Rust crates, C ABI symbols, executable names, data directories, bundle identifiers, or environment variables.
- Move or migrate existing user data.

## Requirements

- User-visible desktop text and application metadata use `SunCode`.
- Product and engineering documentation use `SunCode`.
- PascalCase C++/Rust SDK handle names and QML namespaces use `SunCode`.
- The macOS icon resource no longer carries the obsolete mixed-case spelling.
- Lowercase compatibility surfaces remain unchanged.

## Edge cases

- QML resource URLs must use the same casing as the module URI generated by CMake.
- Case-insensitive macOS filesystems must still record the icon filename casing change.

## Acceptance criteria

- No source or tracked documentation contains the legacy mixed-case spelling.
- The Qt desktop target builds successfully.
- The application reaches the Qt event loop without QML load errors.

## Open questions

- None.
