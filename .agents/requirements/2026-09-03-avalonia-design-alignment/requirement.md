# Requirement

Align the Avalonia desktop client with the normative `DESIGN.md` and the matching design-system desktop specimens, including confirmation flows, network certificate controls, conversation states, review states, and geometry.

## Acceptance criteria

- Consequential session archive uses an explicit confirmation step.
- Network exposes certificate trust source and custom certificate file selection.
- Composer supports shared expanded drafting with live character count.
- Thinking, context compaction, failed-turn, and tool detail output states are represented. Live tool streaming remains dependent on a future SDK event contract.
- Workspace and drawer geometry follows the documented dimensions and window-boundary rules.
- Settings uses the specimen's surface hierarchy, compact ungrouped navigation, shared two-column setting rows, section spacing, subordinate certificate layout, provider overview, provider detail actions, and model chips.
