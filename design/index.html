05 / Review rules

Keep the desk quiet

Use these rules when proposing a new module, state or component.

Conversation first

The center is the primary work surface. Collapse side bays before reducing its reading width.

Status lamp rule

A color must explain an action, a state or a change. Decorative color is not part of the system.

Native focus

Keyboard targets retain a visible two-step accent ring. Icon-only actions carry an accessible label.
