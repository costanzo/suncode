# Desktop Project

This project boundary reviews the five Avalonia desktop windows: ProjectHub, Workspace, DialogWindow, Settings, and About. Workspace alone owns a custom 36px title bar; the other four specimens begin at the client area because their title bars and window controls are supplied by the operating system. `project-hub/` mirrors the actual `ProjectHubWindow.axaml` content using component-owned React specimens for buttons, project rows, and empty state. `workspace/` also previews the title-bar project switcher: its menu puts Open project first, separates recent projects with a divider, and shows only each project's name and path. Selecting a project opens a new Workspace window or focuses its existing window without exposing that window state in the menu. `dialog-window/` documents the focused secondary-confirmation window; it starts closed and opens its shared confirmation dialog only after the action is clicked. `settings/` is a dedicated, independently routable design surface for Defaults, Appearance, Keyboard shortcuts, Network, MCP servers, Language servers, Logging, Updates, built-in Agents, and Model providers. Language servers specify project-scoped semantic analysis for agent coding tasks while preserving the read-only editor boundary. Keyboard shortcuts are currently a read-only catalog of command/key combinations; customization is intentionally deferred. `about/` identifies the installed Desktop and Agent SDK versions separately; the latter is queried from the embedded Rust agent core and remains distinct from its internal C ABI compatibility number.

Settings → Updates (`#/projects/desktop/settings/updates`) is a design-review proposal for Desktop/C# coordination of independent Desktop and Rust Agent SDK updates. About → Software updates navigates to that destination, representing the contract to close About and open Settings. Checks, downloads, verification, and restart are simulated in memory; no production updater functionality is implemented by these specimens. The Settings README and root `DESIGN.md` describe the state and layout contract.
