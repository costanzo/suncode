# Desktop Project

This project boundary reviews the five Avalonia desktop windows: ProjectHub, Workspace, DialogWindow, Settings, and About. Workspace alone owns a custom 36px title bar; the other four specimens begin at the client area because their title bars and window controls are supplied by the operating system. `project-hub/` mirrors the actual `ProjectHubWindow.axaml` content using component-owned React specimens for buttons, project rows, and empty state. `workspace/` also previews the title-bar project switcher: its menu puts Open project first, separates recent projects with a divider, and shows only each project's name and path. Selecting a project opens a new Workspace window or focuses its existing window without exposing that window state in the menu. `dialog-window/` documents the focused secondary-confirmation window; it starts closed and opens its shared confirmation dialog only after the action is clicked. `settings/` mirrors `SettingsWindow.axaml` as a dedicated, independently routable settings surface with Defaults, Appearance, Keyboard shortcuts, Network, Logging, and Model provider pages. Keyboard shortcuts are currently a read-only catalog of command/key combinations; customization is intentionally deferred. `about/` identifies the installed Desktop and Agent SDK versions separately; the latter is queried from the embedded Rust agent core and remains distinct from its internal C ABI compatibility number.
