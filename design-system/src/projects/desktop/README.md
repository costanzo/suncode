# Desktop Project

This project boundary reviews the five Avalonia desktop windows: ProjectHub, Workspace, DialogWindow, Settings, and About. Workspace alone owns a custom 36px title bar; the other four specimens begin at the client area because their title bars and window controls are supplied by the operating system. `project-hub/` mirrors the actual `ProjectHub.axaml` content using component-owned React specimens for buttons, project rows, and empty state. `dialog-window/` documents the focused secondary-confirmation window; it starts closed and opens its shared confirmation dialog only after the action is clicked. `settings/` mirrors `SettingsWindow.axaml` as a dedicated, independently routable settings surface with General and Model provider pages.
