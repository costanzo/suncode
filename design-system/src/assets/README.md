# Design Assets

This is the central asset catalog for the SunCode design system and review pages. It is organized by reusable ownership rather than by consuming page.

## Brand

The approved source is the review sheet at `../../public/assets/logo.svg`. All brand exports are generated by `tools/brand-assets/` from the repository root.

- `logos/suncode-mark.svg`, `suncode-mark-24.svg`, and `suncode-mark-16.svg`: transparent, tintable marks with main and optical geometry. The `-light`/`-dark` exports have explicit theme colors for image consumers.
- `logos/suncode-logo.svg` and `suncode-logo-small.svg`: application icon with the graphite plate; the small name remains a compatibility alias.
- `logos/suncode-logo-{32,64,128,256,512,1024}.png`: application rasters. Choose at least twice the displayed size for Retina surfaces.
- `platform/suncode-desktop.icns`: generated multi-resolution macOS packaging icon.
- `platform/suncode-macos.svg`: macOS Dock composition with the application plate scaled to 824px inside a transparent 1024px canvas; matches the runtime PNG and ICNS.
- `public/assets/favicon.svg`, `.ico`, and `apple-touch-icon.png`: browser and home-screen exports.

Use the shared `BrandMark` component for themed product identity. Review main/24px/16px marks and application icons on both backgrounds at `#/core/assets/brand`. See root `DESIGN.md` for usage rules and `tools/brand-assets/README.md` for regeneration. Do not use the entire reference sheet as a product image or hand-edit generated copies.

## Icons

The `icons/` directory contains the approved interface icon set used by the Avalonia client and React review browser. Icons are monochrome source assets; the consuming surface applies the semantic foreground token.

New icons should remain simple, 24px viewBox SVGs with a consistent stroke language. Add the icon to this catalog before using it in a client view.

The `fonts/seti.woff` asset is the licensed Seti UI glyph font used only by the universal File Icon review component. Its MIT attribution and source path are recorded in `fonts/SETI-NOTICE.md`.

## Platform And Window Controls

- `platform/suncode-desktop.icns` - generated macOS application icon.
- `window-controls/` - platform window-control states used by the desktop chrome.

The application currently packages its own build-local copies under `apps/desktop-avalonia/Assets/`. Those copies are packaging inputs; this directory is the review catalog and source inventory for visual assets.
